# JavaScript Practice Lab

A collection of JavaScript coding exercises, basic algorithms, and small web projects built with HTML, CSS, and vanilla JavaScript.

This repository serves as a practical space to explore programming concepts, improve problem-solving skills, and experiment with fundamental frontend development techniques.

## 🚀 Overview

The project includes small, self-contained exercises focused on JavaScript logic, algorithm implementation, and interactive web pages.

## 🛠️ Technologies

- **HTML5** — Page structure and semantic markup.
- **CSS3** — Styling, layouts, and basic responsive design.
- **JavaScript (ES6+)** — Algorithms, DOM manipulation, and interactive functionality.
- **Git & GitHub** — Version control and project management.

## ▶️ Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/javascript-practice-lab.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript-practice-lab
   ```

3. Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.

No additional dependencies are required for the basic exercises.
